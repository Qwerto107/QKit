# 诗词密码数据

`poetry.json` 是构建前生成的本地数据，页面运行时不请求第三方诗词或翻译接口。

- `text` 为诗句，`from` 和 `by` 分别为作品与作者，`id` 为唯一标识。
- `pwd` 保存按声调、分句大写及字符替换规则预先计算的默认密码。
- 分词与英文标签：使用 `jieba.posseg` 和 `pygtrans` 在数据生成阶段完成。
- `words` 中的 `start`、`end` 是密码字符的半开区间，与标点移除后的密码对齐；`word` 为中文原词，`label` 为英文辅助标签，`pos` 为 Jieba 词性。
- `initials` 保存未替换数字或符号的拼音首字母，保留原来的分句大写；关闭数字或符号替换时，用它恢复对应字母。默认选项使用原始 `pwd`。
- `poetry-english.json` 是人工整理的常见名词、动词对照表。英文替换默认关闭；开启后仅在词性为名词或动词、且词表存在对应项的分词中随机选择一处替换。替换片段保留原中文区间，继续用于联动高亮。
- `length` 保留原始数据的含标点字数。前端按原句去掉标点和空白后的字数筛选，密码位数单独计算。
