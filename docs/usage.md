# 使用指南

[项目首页](../README.md) · [文档中心](README.md) · [部署指南](deployment.md)

在左侧或移动端顶部选工具。六种配色与深浅主题可独立切换。浏览器会记住配色、主题、随机密码选项和手动保存的诗词密码配置。生成的密码、密钥、JWT 和文件不写入本地存储。

## 密码生成

- **随机密码**：打开页面自动生成，默认 24 个。勾选「排除指定字符」可填写要排除的字符，取消勾选会暂停排除并保留输入。点击「一键均分」，按当前密码长度和可用字符填入各类最少数量，可继续逐项调整。配置自动保存在当前浏览器，也可点击「保存配置」手动保存。「重置配置」恢复默认值。鼠标停在最少数量、密码长度或生成数量的控件上时，可用滚轮增减。
- **诗词密码**：随机从本地词库选择诗句。默认每批 8 条，诗句在 12～18 字之间，不计标点和空白。调整范围时，批量数量会按可用诗句数收缩；范围扩大后恢复设定值。
- 诗词密码可切换分句首字母大写、数字及符号替换。英文词替换默认关闭；打开后按本地词表从符合条件的名词或动词中挑一处替换。没有匹配词时保留原结果。点击分词可联动高亮原句和密码片段，点击密码可以复制。
- 「重置」只恢复诗句字数；「保存配置」和「重置配置」作用于整组设置。诗词密码可当作灵感，不建议直接使用生成结果。

## 图片与文件

| 工具 | 操作 |
| --- | --- |
| 图片加水印 | 选择、拖入或粘贴图片，设置字体并选择平铺、单个或指定数量。字体默认跟随系统。浏览器支持本机字体访问时，可点击「本机字体」授权加载。颜色默认黑色，字号为短边 4%，不透明度 5%，旋转 −35°，平铺间距 5。支持取色器、RGB 和 HEX。用「下载 PNG」保存单张，用「打包下载」保存多张。 |
| 盲水印查看 | 优先使用原始 PNG。在「图像视图」选择原图、反色、灰色像素、随机色图、英文通道或位平面。比如 `Green Channel` 查看整个绿色通道，`Green Plane 1` 查看从 0 开始计数的第 1 位。可用左右方向键切换。 |
| 二维码 | 输入文本或链接生成二维码并下载 PNG；识别时可选择、拖入或粘贴二维码图片。识别出的链接以纯文本展示。 |
| 动态二维码传输 | 一台设备选择文件并循环播放，另一台使用摄像头扫描，或批量导入二维码图片。可重复扫描或补扫缺帧。全部收到后再下载文件，单次上限 2 MiB。 |
| 丑丑头像生成 | 打开即生成手绘头像，点击「换一个」重新生成，支持下载 PNG。基于 Xuan Tang 的 Ugly Avatar 改编，按 CC BY-NC 4.0 使用。 |
| 简单头像生成 | 打开即生成几何头像，点击「换一个」重新搭配图形和配色，支持下载 PNG 或 SVG。基于 Xuan Tang 的 Simple Avatar 改编。 |

图片加水印和盲水印查看可以直接在图上滚轮缩放，按住拖动，双击还原。键盘聚焦后可用加减键缩放、按 0 还原。缩放不会改变导出尺寸。

盲水印视图只展示像素特征，不能单凭结果确认图片是否含水印。JPEG 压缩、截图或重新转码可能已经改变像素低位。

## 数据转换

| 工具 | 说明 |
| --- | --- |
| Base64 | 选择文本或图片后，直接点击「编码」或「解码」。选择图片会自动生成 Data URI，也可粘贴完整 Data URI，点击「解码」预览并下载图片。图片上限 20 MiB。 |
| URL | 输入或粘贴 URL 或查询字符串，下方自动逐行显示参数名和值。需要转换时，选择对应模式并点击「编码」或「解码」。拖动任一文本框右下角可同时调整两框高度。 |
| AES / DES | 加密与解密时应使用相同模式、填充、Key 和 IV。Key 与 IV 默认按 UTF-8 读取，以 `hex:` 开头时按十六进制处理。AES-GCM 使用 12 字节 IV，输出附带 16 字节认证标签。 |
| 哈希散列 | 支持 SHA-1、SHA-2、SHA3-256、RIPEMD-160、SM3 和 HMAC。 |
| MD5 | 支持文本及分段读取文件，输出可选 16/32 位和大小写。 |
| 时间戳 | 可互转秒、毫秒与日期，支持 UTC、UTC+8、固定 UTC−5 和 UTC+9。 |

DES、3DES、MD5 和 SHA-1 用于处理已有格式。新的加密用途优先选 AES-GCM，同一密钥下不要重复使用 IV。

## 开发工具

| 工具 | 说明 |
| --- | --- |
| JSON 格式化 / 校验 | 可调整缩进或压缩，保留大整数原文和重复键。结果按层级着色。语法有误时可查看错误说明和原始信息，浏览器提供位置时可查看附近原文并跳转。拖动任一文本框右下角可同时调整两框高度。 |
| JWT 解码 | 解码三段式 JWT，按 UTC 显示 `iat`、`nbf`、`exp`。过期状态以本机时间为准，工具不验证签名。 |
| UUID / ULID | 默认生成 10 个，可调整为 1–100 个。点击任一结果整行即可复制，也可复制全部。 |
| 文本 Diff | 逐行对比原文与修改后文本，标出添加和删除。 |
| 正则测试 | 选择 JavaScript、PHP（PCRE2）或 Go（RE2）语法，勾选查找全部、忽略大小写等匹配选项。高级选项随语法切换。结果会高亮匹配并显示捕获组。 |
| 进制转换 | 转换有符号整数的二、八、十、十六进制。 |
| 颜色转换 | 拖动色盘、选预设色，或输入 HEX、RGB 和 HSL，查看色块和换算值。 |
| Cron 解析 | 支持标准 5 字段和秒数在前的 6 字段表达式；输入 IANA 时区（如 `Asia/Shanghai`），预览接下来 5 次执行时间。 |
| Nginx 配置生成器 | 选择静态站点、SPA 或反向代理，勾选所需配置即可预览、复制或下载 `.conf`。生成的文件放在 Nginx 的 `http` 块中，也可以通过 `include` 引用。 |

### Nginx 配置

- 域名或 IPv4 地址可填写多个，用空格或逗号分隔。启用 HTTP 跳转 HTTPS 后，可选择 301、302、307 或 308，默认 302。跳转使用首个域名。自动跳转省略端口选项适用于 Nginx 自行构建的重定向地址。

- 开启 SSL / HTTPS 后会预填 `/etc/nginx/ssl/fullchain.pem` 和 `/etc/nginx/ssl/privkey.pem`，部署时填实际文件路径。TLS 默认启用 1.2 和 1.3。TLS 1.2 使用 `ssl_ciphers`，TLS 1.3 使用 `ssl_conf_command Ciphersuites`。同一监听地址和端口有多个站点时，应在默认站点上设置 TLS 协议。
- 两个加密套件下拉框各自支持默认套件、AES-GCM、ChaCha20、TLSRef 推荐套件或自定义。TLS 1.2 采用 Intermediate 的列表。TLS 1.3 采用 Modern 和 Intermediate 共用的列表。协议版本、密钥交换群组和套件协商顺序可单独设置。[TLSRef 配置指南](https://docs.tlsref.org/server-side-tls)
- HTTP/2 需要 Nginx 1.25.1+ 和 `http_v2` 模块。HTTP/3 需要 TLS 1.3、`http_v3` 模块及相同端口的 UDP 监听。PROXY protocol 应与前置负载均衡器配套使用，适用于生成的 TCP 监听。
- HSTS 可随 HTTPS 启用，默认有效期为 31,536,000 秒（365 天），可选覆盖子域名。`max-age=0` 会清除浏览器中该站点的 HSTS 策略。浏览器只接受通过 HTTPS 返回的 HSTS 响应头。
- TLS 高级设置可选择密钥交换曲线、服务端套件优先级、共享会话缓存、会话票据和早期数据。0-RTT 默认关闭，需要 TLS 1.3，上游应用应处理早期数据的重放风险。
- 在「访问控制与响应头」中可勾选搜索引擎爬虫、AI 爬虫和通用标识，也可填写自定义 User-Agent 关键词。命中任一关键词时返回 403，匹配忽略大小写。`robots.txt` 支持允许全部、请求停止抓取和自定义规则。开启 User-Agent 拦截后，爬虫仍可读取这份文件。[Robots Exclusion Protocol](https://www.rfc-editor.org/rfc/rfc9309.html)
- 按 IP 限流超额返回 429。CORS 支持填写来源、勾选常用方法和请求头，也可补充自定义名称。携带凭据时须指定具体来源。CSP 策略通过响应头交给浏览器执行。
- 访客 IP 可使用连接来源、`X-Forwarded-For`、`X-Real-IP`、PROXY protocol 或自定义请求头。使用 CDN 自定义头时，将实际回源 IP 或网段填入可信代理地址。请求头与 PROXY protocol 方式需要 `http_realip` 模块。
- Gzip 和 Brotli 可分别设置动态压缩级别、最小响应大小和 MIME 类型。静态站点与 SPA 可发送已有的 `.gz` 或 `.br` 文件，需要对应静态模块。Gzip 还可设置 `Vary: Accept-Encoding` 和带 Via 的请求压缩策略。
- 开启「自定义日志」后可设置日志路径和错误日志级别，并可开启「自定义访问日志格式」。点击「查看可用变量」可查看变量说明，例如 `$remote_addr "$request" $status $request_time` 可记录访客 IP、请求行、状态码和耗时。输入多行时合成一行。使用 JSON 日志时，在格式内容中填写 JSON 结构并选择「JSON 转义」。同一个 `http` 块内的自定义格式名称须唯一。
- 反向代理可添加多条转发规则，同时命中时使用最长的匹配前缀。匹配路径为 `/` 时匹配全站，`/api` 也匹配 `/api-v2`，`/api/` 匹配以 `/api/` 开头的路径。匹配路径为 `/api/` 时，请求 `/api/items?x=1` 的转发结果如下。每条使用 HTTPS 上游的规则需填写 CA 证书路径。

| 上游路径 | 上游收到的请求 |
| --- | --- |
| 留空 | `/api/items?x=1` |
| `/` | `/items?x=1` |
| `/backend/` | `/backend/items?x=1` |
